# 价值量化模型

> **本文件是内部测算模型，不进文档。** 文档里只出现结论数字，加一句自然语言的测算基准（如「按 30 支队伍、每队 2—4 人测算」），不出现公式与推导链。
> 变量：**N** = 队伍数；**P** = 每队人数；**T** = 赛道数；**D** = 现场天数。

---

## 1. 内容产出

| 产出 | 公式 | 30 队示例 |
|-|-|-|
| 主视频 | N 条（每队 1 条，30—60 秒） | 30 条 |
| 传播切片 | N × 3 条（每队 3 条，6—15 秒） | 90 条 |
| 视频合计 | N × 4 条 | 120 条 |
| 视频总时长 | N × (0.5—1 min) + N × 3 × (0.1—0.25 min) | 24—52 分钟 |
| 图文 | N × (1—2) 篇 | 30—60 篇 |
| 内容合计 | 视频 + 图文 | 150—180 条 |

**自洽要求**：以上只在「全部队伍都交视频」时成立。
- 若视频只由部分赛道产出 → 必须写成区间（如主视频 0.5N—N 条）。
- 若客户希望拿到足量视频 → 反向在赛道规则里给**每条赛道**都加一条 30—60 秒视频交付项（文创赛道的视频可定义为"作品演绎片"）。

## 2. 传播

| 指标 | 公式 | 说明 |
|-|-|-|
| 传播窗口 | 赛前 2 周 + 现场 D 天 + 赛后 2 周 | 覆盖客户的关键节点（如红叶季、节庆、大促） |
| 发布账号 | ≥ 到场创作者数 = N × (2—3) | 创作者自有账号 + 客户官方账号 |
| 全网曝光 | 创作者账号体量 × 发布条数（估算） | **必须标注「预估，以实际数据为准」** |
| 到访 / 转化引导 | 曝光 × 0.06%—0.17% | 霞客松口径：300—500 万曝光 → 3,000—5,000 人次到访意向 |

## 3. OPC / 创作者资源

| 指标 | 公式 | 30 队示例 |
|-|-|-|
| 现场创作者 | N × P → 建议按 N × (2—3) 估算 | 60—100 人 |
| 可独立交付 OPC | 现场创作者 × 30%—35% | ≥ 20 名 |
| 能力档案 | = 现场创作者数 | ≥ 60 份 |
| 长期合作池 | N × (1/6—1/3) 支团队 + 现场创作者 × (1/6—1/3) 位创作者 | 5—10 支 / 10—20 位 |
| 社群 | 1 个（长期运营） | 1 个 |

## 4. 内容资产与基建沉淀

| 指标 | 公式 | 说明 |
|-|-|-|
| 官方可用素材 | 视频合计 + 图文 | 150—180 条 |
| 常规排期支撑 | 主视频数 ÷ 每周发布量（3—4 条/周） | 30 条 ≈ 2 个月 |
| 客户素材入库 | 客户提供量（建议 ≥100 图 + ≥20 视频） | 结构化 + 打标签 |
| Prompt 模板 | 15 套/赛道（2 赛道 = 30 套） | 按场景分类 |
| 生产 SOP | 1 套 | 选题 → Prompt → 生成 → 剪辑 → 发布 → 数据回传 |
| 视觉规范 + 版式模板 | 1 套 + 10 套 | 客户后续可自行延展 |
| 数据看板 | 1 个 | 发布链接 + 基础传播数据 |
| 培训 | 1 场（2 小时） | 面向客户宣传人员 |
| 客户自助产能目标 | 每周 3—5 条 | 活动结束后的长效目标 |

## 5. 商业转化（文创 / IP / 服务）

| 指标 | 公式 | 30 队示例 |
|-|-|-|
| 现场方案 | 选择该赛道的队伍数（0.5N—N） | 15—30 套 |
| 进入打样 | 方案数 × 15%—25% | 3—5 套 |
| 首批商品化 | 1—2 款 | 1—2 款 |
| 授权方式 | 非独占授权（未入选项版权归创作者） | — |
| 分成建议 | 销售额 5%—10%（双方另议） | — |
