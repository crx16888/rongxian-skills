# 文档骨架：三类活动的章节结构

> 骨架来自贵客松（官方配套赛事）、南客松 S2（对外承办 + 赞助招商）、霞客松（景区文旅定制）三份真实文档。
> 写的时候按骨架逐章落，**不跳章、不留空章**；客户没给的信息写成「待定（建议值）」而不是留白。

---

## A. 黑客松 / 共创赛（完整版，11 章）

| # | 章节 | 必写内容 | 常见坑 |
|-|-|-|-|
| 1 | 活动背景与定位 | 客户现状的 3 条问题 → 活动是什么 → 为什么用共创/黑客松的方式（密度/筛选/延展/可控）→ 核心目标 4—5 条 | 只写"我们办个活动"，不写客户的问题 |
| 2 | 活动基本信息 | 名称 / 组织单位 / 形式 / 时间 / 地点 / 规模 / 参赛对象 / 赛道 / 公众环节 | 规模与后文数量对不上 |
| 3 | 活动日程 | 赛前排期表 + Day1 表 + Day2 表（时间到分钟） | 只有流程图，没有分钟级 Rundown |
| 4 | 赛道与作品要求 | 每条赛道：交付物 / 配套物料 / 发布要求 / 授权要求 | 交付物与第 7 章的产出数字矛盾 |
| 5 | 赛制与趣味设计 | 评分构成（评委分 + 人气分）、各赛道评分维度、组队机制、趣味机制表 | 评分项分值与满分不相等 |
| 6 | 奖项与激励 | 现金奖池表 + 非现金权益 + 发放说明 | 奖金池与报价表的奖金行不一致 |
| 7 | **对客户的价值（量化）** | 一页看清总表 + 逐条展开：OPC / 传播 / 内容资产 / 基建沉淀 / 商业转化 / 成果包 | 只有形容词，没有数字；数字没有口径 |
| 8 | 组织与执行 | 分工框架（客户 vs 我方）/ 人员配置 / 物料清单 / 现场保障 | 分工写成本方独角戏 |
| 9 | 交付物清单 | 赛前 / 赛中 / 赛后交付物 + 形式 + 时间 | 与第 7 章的产出资产不一致 |
| 10 | **预算与报价** | 明细报价表（项目/金额/成本说明）+ 报价口径（含-不含）+ 可调整项 | 没有"不含"边界；没有压降顺序 |
| 11 | 执行排期 | T-21 → T+14 节点表 | 与第 3 章赛程时间冲突 |

**结尾固定放**：作品归属 / 版权与授权说明（一段 callout）。

## B. Workshop（精简版，7 章）

1. **背景与目标**：客户为什么要办这场 workshop（1 段 + 3 条目标）
2. **形式与产出**：形式（讲解 / 实操 / 共创）、时长、产出物（如 prompt 库、原型、方案稿）
3. **议程表**：分钟级（含开场 / 讲授 / 实操 / 点评 / Q&A）
4. **讲师与嘉宾**：人选 + 背景 + 分工（讲师 / 助教 / 点评人）
5. **对客户的价值**：3—5 条，能量化就量化（参与人数、产出物数量、可复用资产）
6. **报价**：明细表（讲师费 / 助教 / 场地 / 物料 / 影像 / 茶歇）+ 含-不含
7. **排期与交付物**：T-14 → T+7

---

## C. 赞助包（不走 11 章骨架）

1. **合作背景**：活动规模、触达人群、上一届数据（用案例库真实数字）
2. **权益-价格对照表**：档位 / 价格 / 权益清单 / 物料需求（用 `assets/赞助包权益对照表-模板.md`）
3. **单项权益说明**：展位、评委席位、Workshop、推文、物料包植入、人才触达、特别单元奖
4. **资源置换选项**：不出现金时的置换口径（奖品 / 硬件 / 物资 / 服务）
5. **交付与排期**：权益兑现时间表（赛前 / 赛中 / 赛后）
6. **其他**：独家保护条款、露出位置确认、结算方式

---

## 写作口径（三类通用）

- **动词化标题**：`更多 OPC`、`更多传播`、`AI 基建` 优于 `价值一`、`价值二`。
- **数字前置**：能写成「≥ 120 条」「4 周」「5%—10%」就不要写「大量」「较长时间」。
- **口径说明必写**：所有推导数字后面跟一句「按 N 支队伍、每队 X 人测算」。
- **客户侧 vs 我方**：分工表两列，客户列写客户做什么，不写"配合"这种含糊词。
- **结尾留钩子**：结语一句短句（如「贵阳出题，贵客开造」这类项目口号），比"谢谢观看"有效。
