## 1. 报价口径（默认写进文档）

**包含**：活动策划、赛务执行、物料设计与制作、影像记录、传播内容制作、赛后成果交付。

**不含**：
- 场地租金与门票（默认客户提供）
- 音响 / 舞台设备（默认客户提供）
- 奖金个人所得税（由组委会代扣代缴）
- 本地选手差旅
- 超出清单范围的临时增项

**其他固定条款**：
- 规模测算基准（如「按 30 支队伍、100 人以内」）；规模变化按实际人数与清单调整
- 版本声明：「本版本为初版报价，最终以双方确认的执行清单与结算口径为准」
- 差旅住宿：本地不报；外地 200 元/人 + 住宿
- 奖金池：客户可选项，未设奖金池时改用证书 / 权益型奖项

## 2. 可调整项（对外 · 写进文档）

> 文档里的写法是「可选配置」：先给标准配置，再说明预算压降时按什么顺序调整、各自影响什么。不写我方的心理价位与底线。


| 顺序 | 模块 | 让法 | 影响 |
|-|-|-|-|
| 1 | 影像配置 | 摄影 + 摄像 + 直播 → 基础摄影 / 手机素材留档 | 只影响素材丰富度 |
| 2 | 嘉宾与导师规模 | 15 人 → 6—8 人核心导师 | 影响点评深度，不影响交付 |
| 3 | 传播包 | 完整传播包 → 基础图文复盘 | 影响赛后声量 |
| 4 | 视觉物料 | 全套设计 → 沿用客户现有视觉，仅做必要延展 | 影响观感 |
| 5 | 住宿范围 | 覆盖全部外地选手 → 只覆盖核心选手 / 定额补贴 | 影响体验 |
| 6 | 奖金池 | 下调单项金额 → 部分改权益型奖项 | 影响报名吸引力 |

## 3. 不建议压缩（对内 · 不进文档）

| 模块 | 原因 |
|-|-|
| 选手招募与审核 | 决定到场质量，人不对一切都白做 |
| 现场执行团队 | 签到、控场、计时、应急决定体验下限 |
| 评审体系 | 没有可信评审，活动就只是聚会 |
| 内容 / 文创产出标准 | 客户买的是资产，砍了就没有交付物 |
| 基础现场保障 | 网络、电力、医疗、保险 |

## 4. 让步梯度与底线（对内 · 不进文档）

| 对方动作 | 我方回应 |
|-|-|
| 一上来砍 30% | 不直接让价，先给定档解释：「这个价对应的是全案级配置」+ 抛出可调整项表，让对方选砍哪一项 |
| 砍 10%—15% | 从顺序表第 1—2 项让，**同时等量减少交付物**（影像从全配降基础、嘉宾从 15 降到 8） |
| 要求"再送一点" | 用非现金权益换：加证书、加入选权益、加赛后社群推荐，不动现金项 |
| 预算明确低于底线 | 降档（全案 → 轻量）+ 缩减规模或时长，**不降单价**；明确告知不含哪些模块 |
| 要求独家 / 排他 | 单独计价，写进赞助包条款，不放在赛事执行费里 |

**底线参考（绝不写进文档）**：客户有场地 ¥35,000 起；我方找场地 ¥55,000 起（自航海实测口径）。

## 5. 报价表书写规范（内部规范）

- 明细行按「项目 / 金额 / 成本说明」三列，成本说明写**口径**（单价 × 数量），不写内部成本、毛利与底线
- 金额格式统一：`¥12,000`（不要写 `¥12,0000` 这类歧义格式）
- 合计行与明细行求和对齐；行号连续
- 明细表之后紧跟「报价口径」与「可调整项」两张表
- 表格里不出现公式推导过程、自检标记（✓ / 校验通过 / 已核对）等工具痕迹
