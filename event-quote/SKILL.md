# 活动方案与报价文档

## 产出定位（先读这条）

**这是一份文档写作 skill。唯一的交付物是一份可以直接发给客户的飞书文档。**

读者是客户的决策人——他们要从中判断：做什么、给谁做、能拿到什么、多少钱、什么时候交付。文档里只放他们看得懂、需要拍板的内容。

- **直接产出成稿。** 参数齐了就一次写完并写进飞书，不要停在"先给大纲确认"。只有关键参数确实缺失时才问，且一次问全。
- **交付物是飞书文档**；本地 md 只是版本备份，不是交付物。
- **写作口吻是方案口吻**，不是工具口吻、不是工程口吻、不是聊天口吻。

**文档里不出现**：
- 数字核对过程——自检表、验算公式、`单价 × 数量 = 小计` 这类过程性内容
- 内部成本、毛利、底价、让步梯度、红线清单
- 脚本输出、TODO、未填占位符、`references/` 引用、skill 名称、流程说明
- "按 XX 模型测算""本 skill""以下为推导链"这类元叙述

**内部核查照做**（见文末「数字纪律」），但核查结果只在对用户的对话里说，不落进文档。

## 触发
- 「写一份活动方案 / 活动介绍 / 报价 / 明细报价 / 赞助方案」
- 「按南客松 / 贵客松 / 霞客松那套来」
- 「客户预算 X 万，给我出一版方案 + 报价」/「帮我算个价」

不适用：纯文案润色、合同与法务条款、非本团队主办的活动。

## 生成流程
1. **收参数**：客户/主办方、活动类型、时长、规模（队伍数 × 每队人数）、赛道数、有无场地、是否含奖金池、差旅住宿规则、传播要求、预算带、交付时间。缺关键项就问，一次问全；非关键项按案例库惯例取合理值并写进文档的测算基准。
2. **定档**：按 `references/02` 的对外价格带选轻量 / 全案 / 旗舰。客户已给预算时，用预算反推可交付范围。
3. **填骨架**：按 `references/01` 的三类骨架逐章写，不跳章、不空章，不留占位符。
4. **算价值**：按 `references/03` 的公式量化「对客户的价值」，把量级写进第 7 章。
5. **出报价**：从 `references/02` 取单价 → 展开明细（项目 / 金额 / 成本说明）→ 求和 → 写含-不含边界与可调整项（口径见 `references/04`）。
6. **写进飞书**：命令见 `references/06`。同时落一份同名本地 md 备份。
7. **自查**：按文末「数字纪律」过一遍，结果只在对话里回复用户。

## 数字纪律（内部执行，不写进文档）
- 每个数字都要能推导：**单价 × 数量 = 小计；小计求和 = 合计**。
- **四处必须互相自洽**：章节标题里的数量词、价值表的合计、报价表的明细、测算基准。对不上就是错误，不是笔误。
- 文档里只保留一句自然语言的测算基准（如「按 30 支队伍、100 人以内测算」），不写推导公式。
- 预估类数字（曝光、到访、转化）要标「预估 / 以实际数据为准」，并让测算依据在句子里说得通。
- 交付物数量必须与赛道规则自洽：只有「每队都交 1 条视频 + 3 条切片」才能推出「30 队 = 30 条主视频 + 90 条切片」；若只有部分队伍产出，就写成区间，或反向改赛道规则让每队都交。
- 发现的事实问题（金额格式、行号、描述与金额不符）**先列给用户决定**，不要默默改掉对方的数字。

## 报价规则
- `references/02` 是**报价基线**，不是可对外披露的成本；文档只呈现「金额 + 成本说明」，说明写口径（单价 × 数量），不写内部成本与底线。
- 默认口径：场地与音响由客户提供；本地选手不报差旅；外地选手 200 元/人 + 住宿；奖金个税由组委会代扣代缴。
- 奖金池是客户可选项：不给奖金池时，改用证书 / 权益型奖项并在文档里说明。
- 报价后紧跟「可调整项（预算压降时的取舍顺序）」——用「可选配置」的口吻写，不写我方的让步梯度与底线。

## 文档写作要求
- **动词化标题**：`更多传播`、`AI 基建沉淀` 优于 `价值二`、`价值三`。
- **数字前置**：能写「≥ 120 条」「4 周」「5%—10%」就不写「大量」「较长时间」。
- **表格承载信息**：量级、档位、排期、口径一律用表，不用大段文字堆。
- **结论先行**：每章开头一句能独立读懂的话，再展开。
- 结尾留一句项目口号式的短句，不要「谢谢观看」。

## 落盘
- 飞书：`lark-cli --as bot docs +update --doc <doc_token> --doc-format markdown --command overwrite --content @./file.md`
  - `@file` **只接受当前工作目录的相对路径**，绝对路径会被拒（unsafe file path）。
  - 文档首行放 `<title>活动全名</title>`，其后用 `#` / `##` 分级且不跳级。
- **若同事已经在文档上手改过内容（尤其是金额），不要 overwrite**，改用定点编辑（`references/06`），否则会抹掉对方的手改。
- 本地：落一份同名 md 作为版本备份与 diff 依据。
