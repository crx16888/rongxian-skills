# 活动方案排版规范

> 适用场景：发给合作方的 Word 活动提案/执行方案。
> 核心原则：**对方打开就能用，不需要装字体、不需要调格式。**

## 为什么用这些字体

| 字体 | 装机率 | 说明 |
|------|--------|------|
| 宋体 | 100% | Windows/macOS 均自带，正文首选 |
| 黑体 | 100% | 标题首选，Windows/macOS 均自带 |
| 微软雅黑 | 95%+ | Windows Vista+ 自带，macOS 需安装 |
| 楷体 | 100% | 可用于引言、署名 |

> ❌ 不要用：Noto Sans CJK SC、思源黑体、苹方 —— 发给 Windows 合作方会掉成默认字体。

> ❌ 不要用：方正系列、汉仪系列 —— 商业字体，未授权不可用于对外文档。

## 格式模板

```
[封面]
微软雅黑 二号 加粗    活动标题
微软雅黑 小三         副标题 / 日期 / 主办方

[正文]
黑体 三号 加粗        一、活动背景
宋体 小四             正文内容...
黑体 四号 加粗        1.1 子标题
宋体 小四             正文内容...

[表格]
宋体 五号             表内文字
黑体 五号 加粗        表头
```

## 正式活动方案内容规范

- 开头保留正式正文：先交代活动背景、合作目标和项目定位，再进入执行信息。
- 不要全篇表格：正文负责说明“为什么做、怎么合作”，表格负责排期、课程、预算、分工、验收。
- 表格文字要短：写“报名通知、现场组织、反馈收集”，不要写成长句。
- 重点必须加粗：金额、课次数量、时长、首期合计、关键交付物、双方责任边界都要加粗。
- 少写空话：不写没有具体动作或交付的宣传句。

## 段落间距

| 位置 | 段前 | 段后 | 行距 |
|------|------|------|------|
| 标题 | 12pt | 6pt | 1.5倍 |
| 正文 | 0pt | 6pt | 1.25倍 |
| 表格内 | 0pt | 0pt | 单倍 |

## 页面设置

| 参数 | 值 |
|------|------|
| 纸张 | A4 |
| 上/下边距 | 2.54 cm |
| 左/右边距 | 3.18 cm |

## 颜色

| 用途 | 颜色 | 色值 |
|------|------|------|
| 正文 | 黑色 | #000000 |
| 一级标题 | 深蓝 | #003366 |
| 重点标注 | 深红 | #CC0000 |
| 超链接 | 蓝色 | #0563C1 |
